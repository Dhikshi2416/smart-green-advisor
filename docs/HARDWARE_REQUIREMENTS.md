# Smart Green Advisor - Hardware Requirements

## 🏠 Smart Home Gateway Requirements

### Minimum Configuration

**Gateway Device:**
- **Processor**: ARM Cortex-A72 (4 cores) or Intel x86-64 (2 cores)
- **RAM**: 4GB DDR4
- **Storage**: 32GB eMMC or SSD
- **Network**: 
  - WiFi 6 (802.11ax) 2.4GHz + 5GHz
  - Gigabit Ethernet (RJ45)
  - Bluetooth 5.0+ with BLE
- **USB**: 3.0+ ports for device expansion
- **Power**: 12V DC adapter with UPS support

**Recommended Models:**
- **Raspberry Pi 4 Model B** (4GB/8GB) - ₹4,500-8,000
- **Intel NUC NUC11PAHi5** - ₹35,000-45,000
- **Custom IoT Gateway** - ₹15,000-25,000

### Advanced Configuration

**High-Performance Gateway:**
- **Processor**: Intel i5-1135G7 or AMD Ryzen 5 5500U
- **RAM**: 16GB DDR4
- **Storage**: 512GB NVMe SSD
- **Network**: 
  - WiFi 6E (802.11ax) with 6GHz support
  - 2.5 Gigabit Ethernet
  - Bluetooth 5.2 + Zigbee + Z-Wave
- **Expansion**: Multiple USB 3.0, PCIe slots
- **Power**: 65W adapter with battery backup

## 🔧 Installation Requirements

### 1. Electrical Requirements

**Main Electrical Panel:**
- **Capacity**: 200A minimum
- **Space**: 2-4 additional breaker slots
- **Grounding**: Proper grounding system
- **Neutral**: Dedicated neutral for smart devices

**Wiring Requirements:**
- **Cat6 Ethernet**: For network connectivity
- **12 AWG Wire**: For high-power devices
- **Conduit**: For outdoor and exposed wiring
- **Junction Boxes**: For device connections

### 2. Network Requirements

**Internet Connection:**
- **Speed**: 100 Mbps+ download, 20 Mbps+ upload
- **Stability**: 99%+ uptime requirement
- **Backup**: Cellular backup recommended
- **Static IP**: Optional but recommended

**Network Configuration:**
- **VLANs**: Separate networks for IoT devices
- **Port Forwarding**: For remote access
- **DNS**: Custom DNS for device discovery
- **Firewall**: Proper security configuration

### 3. Physical Requirements

**Gateway Location:**
- **Central Location**: For optimal WiFi coverage
- **Power**: Dedicated power outlet
- **Ventilation**: Adequate cooling
- **Access**: Easy access for maintenance

**Device Placement:**
- **WiFi Range**: Within 30m of router
- **Bluetooth Range**: Within 10m of gateway
- **Power Access**: Near electrical outlets
- **Mounting**: Proper wall/ceiling mounting
